# Lernapps

Sammlung kleiner Lern-Apps, die direkt im Browser laufen (GitHub Pages). Jede App liegt in einem eigenen Ordner nach Fach.

```
index.html                  Startseite mit Links zu allen Apps
mathe/kopfrechnen/          Kopfrechnen-Trainer
```

Eine neue App anlegen: Ordner `fach/appname/` mit einer `index.html` erstellen und auf der Startseite verlinken.
